# Product Requirements Document

## Product Name

Delivery Pulse

## Product Description

DeliveryPulse is a full-stack project health and risk dashboard for software delivery teams. 

## Problem Statement

Software delivery status is often across Jira, spreadsheets, Slack or Teams messages, emails and status calls. This makes it difficult for stakeholders to quickly understand project health, key risks, blockers, and next steps. 

## Target Users

- IT Project Managers
- Delivery Managers
- Technical Program Managers
- Product Owners
- Software Delivery teams

## MVP Goal

Build a working dashboard that allows a project manager to create projects, track risks and blockers, monitor milestones, and generate simple weekly status reports.
