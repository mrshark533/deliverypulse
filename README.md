# DeliveryPulse

DeliveryPulse is a full-stack health and risk dashboard for software delivery teams.

The application helps Project Managers, Delivery Managers, and technical teams centralize project status, delivery risks, blockers, milestones, and weekly reporting in one lightweight dashboard.

## Problem

In many software projects, delivery information is scattered across Jira, spreadsheets, Slack/Teams messages, emails, and status calls. This makes it difficult for stakeholders to quickly understand project health, key risks, blockers, and next steps.

## Solution

DeliveryPulse provides a simple dashboard where project teams can track project health, manage risks and blockers, monitor milestones, and generate structured weekly status reports.

## Target Users

- IT Project Managers
- Delivery Managers
- Technical Program Managers
- Product Owners
- Software delivery teams

## Initial MVP Features 

- Create and view projects
- Track project health status
- Add and manage risks
- Add and manage blockers
- Track milestones
- Generate a simple weekly status report
